# NepalEntityService-database

> ## ⚠️ This repository is archived
>
> This file-based Nepal Entity Service database has been **superseded by the consolidated Jawafdehi platform**, where the entity dataset now lives in the platform database and is served from [api.jawafdehi.org](https://api.jawafdehi.org). This repository is kept as a public, historical snapshot — it is read-only and receives no further changes.

A file-based database of Nepali public entities — persons, organizations, and government bodies — that powered the Nepal Entity Service API. The dataset remains publicly readable here for reference and reuse; ongoing updates now happen in the consolidated Jawafdehi platform.
